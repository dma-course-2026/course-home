# DMA Data AI 2026 — Course Home

Đây là **cổng thông tin chính** của khóa học DMA Data AI 2026.

Repo này chứa:
- syllabus và roadmap;
- chuẩn đầu ra;
- quy định đánh giá và nộp bài;
- Git workflow và chính sách sử dụng AI;
- hướng dẫn thiết lập GitHub/môi trường;
- lịch học và các milestone;
- thông tin về assignment, mini project và capstone;
- FAQ.

> Học liệu theo từng tuần như slide, notebook, starter code, dataset và đề bài chi tiết nằm trong repo `course-materials`.

## Các repo chính

- `course-home`: thông tin chung, quy định và hướng dẫn.
- `course-materials`: học liệu theo từng tuần.
- Repo cá nhân của học viên: nơi làm và nộp bài.
