# FAQ

## Có cần tạo repo mới mỗi tuần không?

Không. Mỗi học viên dùng một repo cá nhân xuyên suốt khóa học.

## Có cần clone lại repo mỗi tuần không?

Không. Clone một lần. Mỗi tuần cập nhật `main` rồi tạo branch mới.

## Tôi có thể dùng nhiều IDE khác nhau không?

Có. Git quản lý file, không phụ thuộc IDE.

## Branch tuần mới có chứa file các tuần trước không?

Có, nếu branch được tạo từ `main` mới nhất. Đây là hành vi bình thường.

## Pull Request tuần này có hiển thị lại bài cũ không?

Không, nếu bài cũ đã nằm trong `main` và không bị sửa. PR chủ yếu hiển thị phần khác biệt của branch hiện tại so với `main`.

## Có cần giữ branch sau khi merge không?

Không bắt buộc. Có thể xóa sau khi merge.

## Sửa bài sau feedback thế nào?

Sửa trên cùng branch, commit và push tiếp. PR cũ tự động cập nhật.

## Khi nào được tính là đã nộp bài?

Theo quy ước mặc định, thời điểm tạo Pull Request đầu tiên là mốc submission, trừ khi instructor thông báo khác.

## Có được dùng AI không?

Có, nhưng phải khai báo và tự kiểm tra kết quả.

## Có được push `.env`, API key hay password không?

Không.
