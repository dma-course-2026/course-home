# Weekly Assignment

## Mục tiêu

Bài tập tuần dùng để:
- củng cố nội dung vừa học;
- tạo thói quen thực hành;
- luyện Git workflow;
- giúp instructor phát hiện lỗi phổ biến sớm.

## Minh chứng

Tùy tuần, bài có thể là:

- Notebook;
- Python script;
- SQL;
- diagram;
- dashboard artifact;
- README/report;
- code/config phù hợp.

## Mức độ

- **Core**: phần bắt buộc.
- **Stretch**: phần nâng cao tùy nhóm/khả năng.

## Submission

Bài được nộp bằng Pull Request từ branch:

```text
hw/wXX-topic
```

vào:

```text
main
```

## Khi chưa đạt

Học viên sửa sau feedback trên cùng branch và PR hiện tại.
